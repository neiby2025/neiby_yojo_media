
# Neiby 養生メディア（neiby_yojo_media）

## 概要

**Neiby 養生メディア**は、
東洋医学の考え方をもとに、
日々の体調管理やセルフケアをサポートすることを目的とした
**養生情報メディアの試作プロジェクト**です。

**学習・検証を目的とした開発途中のプロジェクト**です。

---

## 背景・目的

東洋医学は難解であり、うさんくさいものという印象があります。
しかし、実際には数千年の歴史からの経験則に基づく医学であるということを広く知ってもらいたいと考え
このメディアを作成しました。

本プロジェクトでは、

* 東洋医学の知識を現代にどう活かすか
* 体調・症状・生活習慣を自分で振り返りやすくする

を考えるための **実験的なメディア**として制作しています。

---

## 現在の内容

* 養生・体調管理に関する情報整理
* 東洋医学的な考え方の構造化（試行中）
* WebメディアとしてのUI・構成検討

※ 機能実装・データ解析部分は今後追加予定です。
